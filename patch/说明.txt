## 使用方法

### 方式1：直接替换文件
将对应文件复制到 AyuGramDesktop 源码的相同路径下即可。

### 方式2：应用补丁
```bash
cd AyuGramDesktop
git apply patch/anti-recall.patch
```

注意：如果上游更新了这些文件，补丁可能产生冲突，需要手动合并。
